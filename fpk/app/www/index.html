播放器接入

全部输出地址一览。地址固定不变，内容每天自动更新。同一个地址可被多个软件共用，按需复制。
① 一条搞定（推荐先试这个）
fongmi.json推荐
FongMi TV（手机/平板/盒子）— 一条配置同时带好直播、回看、节目单，不用另填 EPG。
tvbox.json配置
TVBox / 影视仓 — 影视库一体，直播是其中一个入口；填「配置地址」即可。
② 直播清单 M3U（按回看语法分三种，选错软件会没有回看）
fongmi.m3u${(b)} 语法
FongMi TV（只要直播时）、酷9、电视直播 mytv-android — 这三个的回看变量都是 ${(b)yyyyMMddHHmmss}。
iptv.m3u8{start} 语法
DIYP、天光云影、TVBox 直接填 M3U、多数通用播放器/盒子 — 标准回看变量 {start}/{end}。
kodi.m3u${start} 语法
Kodi（PVR IPTV Simple Client 插件专用）— 回看变量是 ${start}/${end}，不要和其他软件的混用。
③ 节目单 EPG（XMLTV，多个软件共用同一个）
epg.xml通用 XMLTV
酷9（解析格式需手动改成 XmlTV）、DIYP、Kodi、电视直播、大多数支持 XMLTV 的播放器。
说明：FongMi 与 TVBox 用上面两条「配置地址」时已自带节目单，不必再填这条。
④ 数据类文件（不是给播放器填的，供查看/二次开发）
4k.json数据
全部 4K 频道清单，带实测分辨率与编码（H.264/H.265）。给播放器填不了，用于单独筛选 4K 台或排查设备能否硬解。
channels.json数据
频道全量索引（分组、台号、当前/下一档节目、多清晰度地址）。给播放器填不了，供自建应用或脚本取用。
回看语法对不上时，软件能播但回看会失效或报错——遇到这种情况先检查是不是用错了上面三种 M3U 之一。

按软件对号入座

FongMi TV
填 fongmi.json 一条即可（直播+回看+EPG 全包）。只想看直播不想要节目单时，改填 fongmi.m3u
酷9
直播源填 fongmi.m3u，EPG 另填 epg.xml； EPG 解析格式必须手动改成 XmlTV，否则节目单一直空着
电视直播 (mytv-android)
同酷9：fongmi.m3u + epg.xml，格式自动识别为 XMLTV
TVBox / 影视仓
优先填 tvbox.json（一条全包）；若只想要直播，填 iptv.m3u8
DIYP
「节目地址」填 iptv.m3u8，「EPG 接口」填 epg.xml
Kodi
装 PVR IPTV Simple Client：M3U 填 kodi.m3u，XMLTV 填 epg.xml
天光云影
填 iptv.m3u8（扫码/网页推送方式导入）。不支持回看，且项目已停更

4K 频道注意

编码
M3U 里 — 个 4K 台，多数是 H.265/HEVC。 设备不支持 HEVC 时会有声音、画面全黑，这不是源的问题，电视端一般能硬解
真伪
「超高清 / 4K 组」里有部分是「高清臻享」，实测只到 1080P，看 4k.json 的 real_4k 字段即可分辨
江苏移动原版节目清单
完全照搬机顶盒电视墙的 11 个原分组（超高清 / 央视 / 本地 / 卫视 / 体育 / 专业频道 / 影视 / 少儿 / 生活 / 广播 / 购物）， 台号、台名均按上游原样，不做任何二次拆分或改名。
与上面「全部地址」里的清单是两套独立产物，可同时使用、互不影响。
orig.m3u8原版
原版 11 组直播清单。DIYP、天光云影、通用播放器/盒子（回看语法 {start}/{end}）。
orig_epg.xml原版
原版清单配套节目单（XMLTV）。DIYP、酷9、Kodi 等，与 orig.m3u8 配对使用。
orig.json数据
原版分组与频道的结构化清单（含当前节目）。给播放器填不了，供查看原版分组构成。
原版清单的特点与代价：「本地」组把江苏省级台和 13 地市县区台混在 67 台一坨， 「专业频道」19 台内容杂糅，「超高清」里混着实测 1080P 的臻享台 —— 电视墙原样如此，不作修正。

说明与限制

网络要求 直播源由运营商按来源 IP 放行，需在江苏移动宽带下才能播； 其他网络下只能生成节目单与台标
4K 编码 4K 频道多数是 H.265/HEVC。播放设备不支持 HEVC 时会只有声音、画面全黑， 这不是源坏了
不含凭据 生成的文件不带账号、密码、MAC 或机顶盒绑定信息，发布前有 4 类规则强制扫描
使用范围 个人自用。运营商 CDN 有并发与频次限制，请勿大规模传播
应用设置 端口、地市、天数、输出模式在飞牛「应用设置」里改；改端口会自动重启服务
