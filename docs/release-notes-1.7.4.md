## v1.7.4 修订包

- 「设置 → 自定义分组」支持新建、改名和调整组顺序。点频道旁的「分组」可以移动频道、加入多个组、隐藏或恢复自动归类。
- 每个组的频道顺序可独立调整。手机和电脑都可点 ↑ / ↓，电脑也可组内拖动。点「保存分组」后执行一次「立即更新」，再切换到「观看 → 自定义」检查。
- 智能、原版和自定义可分别订阅。自定义提供通用、Kodi 和 FongMi 清单，共用 `epg.xml`。`fongmi.json` 中可选择三套分组。
- 观看页台标使用深色光晕底，浅色台标更容易辨认。

已安装撤下的旧 1.7.4 时，请先备份配置和数据，再卸载旧包并安装当前修订包。同版本覆盖可能被飞牛跳过。安装或升级后执行一次「立即更新」以生成三套清单。
