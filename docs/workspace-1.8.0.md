# jsydiptv 1.8.0 本地改造记录

**状态：本地验收候选，未提交、未发布、未安装到 fnOS。** 延续 1.7.3 候选的整代原子切换、FongMi 双模式产物及 EPG 开关，未改变运营商数据接口或第三方播放器清单协议。

## 功能与优先级

| 优先级 | 功能 | 用途与主流程 |
|---|---|---|
| P0 | 直播与回看状态分离 | 频道→节目→回看；节目结束后可选。停止/换台作废旧回看请求；明确返回直播，同一页面仅一个播放器。 |
| P0 | 北京时间与跨日节目 | 浏览器处于其他时区时也按节目源时间展示。跨午夜节目同时出现在相邻两天，回看请求仍传原始起止时间。 |
| P0 | 更新反馈与旧产物保留 | 设置→更新→验证；轮询不覆盖表单草稿，失败持续展示原因和旧清单可用性。精简/完整、EPG 开关保存后可显式应用；不自动发起更新。 |
| P0 | 运行版本 | `fpk/manifest` 定义 `1.8.0`，打包时注入 `www/VERSION`，服务通过 `/api/status.version` 提供，右上角渲染 `v1.8.0`。未打包的本地源码运行时回读 manifest，取不到时显示「版本 —」。 |
| P1 | 频道筛选与最近频道 | 名称/台号搜索、收藏、最近、可回看、实测真 4K；上一台/下一台跟随当前搜索和筛选。收藏与最近 12 个频道选择仅保存在当前浏览器，不记录节目时段或流地址。 |
| P1 | 只看可回看节目 | 选台→按日浏览→只看可回看；标记有回看的日期、当前档和已选档，选同台不重置已选日期。EPG 关闭/加载失败/无数据分别处理。 |
| P1 | 按播放器订阅 | 选播放器→复制首选入口；FongMi、TVBox、Kodi、通用 M3U、XMLTV 和原版三件套保留。复制当前访问 origin 下的地址，完整模式额外入口按活动产物启用；此行为不改变清单内 URL 的生成规则。 |
| P1 | 可操作的播放失败 | HEVC 不支持时优先试播已知低清直播档，或指引复制到外部播放器；回看不会降档切回直播。通用网络错误提供重试和外部打开；规格探测移入按需展开。 |
| P2 | 目录、构建及验收归类 | 根目录不再保留散落安装包、构建指纹、历史文档、上游快照。统一路径和核对流程，归档不等于回滚资格。 |

## 界面决策与多轮视觉复核

- 三个页面：**观看**放频道与节目单、**订阅**先选播放器、**设置**集中更新和输出。锚点导航支持前进/后退，切页不销毁播放器。空状态直接聚焦频道搜索；移动端提供节目单跳转，次要播放操作归入「更多」。
- 第 1 轮：Chromium 实际截图和交互基线。发现空播放器占屏、重复状态、订阅主按钮不突出、时间控件受浏览器本地格式影响。
- 第 2 轮：收紧空态、隐藏无效控件、强调主复制、使用 24 小时时间、补「应用到清单」。复查发现 HEVC 故障操作主次和低数据量留白仍需调整。
- 第 3 轮：突出外部播放器可用路径，按内容收紧目录/节目单，加入 280 台长文本压力样例，验证 320/390/768/1440 px 下三个页面无横向溢出。截图发现设置卡底部和反馈残留问题。
- 终验：实测桌面保存按钮基线相差小于 2 px；切页清除上个页面的 toast。保留长名称悬停、键盘焦点展开及列表可滚动提示。浅色桌面和深色手机实际截图在 `verify/out/1.8.0/`；所有数据均为合成样例。
